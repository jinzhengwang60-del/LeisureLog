# 页面动画

[返回项目首页](../README.md)

2026-10-13 为六套风格增加细腻、自然的公共动画层。动画只改变呈现，不改变计时、分类、筛选或归属。

## 使用

打开任意页面右上角的“界面风格”，在“动态效果”中勾选或取消“轻柔动画”。偏好仅保存在当前浏览器，刷新和切换页面后继续生效；存储被禁止时本次仍可切换，并提示无法保存。系统启用“减少动态效果”时优先使用静态界面。

- 支持的浏览器中，页面导航和风格切换使用短暂淡入淡出。导航仍使用原有链接和浏览器历史。
- 首页和统计卡片在首次进入视口时轻轻上移、淡入；项目与作品卡片按顺序出现。
- 活动列表只在查询条件或分页改变时播放入场，相同查询的刷新保持稳定。条形统计首次显示时展开，不逐帧修改数字。
- 按钮、导航、筛选、提示与设置菜单增加短过渡。旧电脑和掌机采用更短的反馈，保留原按键样式。
- 弹窗使用原生开合，保留 Escape、焦点和模态语义；支持 CSS 离散过渡的浏览器能看到关闭动画。

## 模块

`src/leisurelog/api/static/motion.js` 管理独立的 `leisurelog:motion` 偏好、可取消的短动画和按查询去重的入场；`motion.css` 定义公共交互与原生过渡。八个页面入口均加载这两个本地文件。

动画使用独立的 translate / scale 属性，保留手帐卡片原有的旋转。单批最多动画 16 项，延迟封顶 168ms；不增加常驻绘制循环。异步列表通过显式 reveal 调用接入，避免全页监听数据刷新。

关闭动画会取消本模块正在播放的效果，并停用动画样式表。减少动态效果的系统偏好有独立 CSS 后备规则。浏览器不支持视图过渡或动画 API 时，界面仍正常更新；动画效果按浏览器支持程度退化。

原生过渡依据：[弹窗动画](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#animating_dialogs)、[页面视图过渡](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@view-transition)。

## 验证

`tests/js/motion.test.cjs` 检查刷新去重、系统减少动态效果、播放中取消、偏好恢复、存储失败和视图过渡后备。现有界面风格测试继续验证加载失败、重复切换和偏好保存；页面资源测试覆盖八个入口。

本次验证：30 项 Node 界面行为测试通过，页面资源测试覆盖八个入口并通过。内置浏览器实际检查八页加载、六套风格连续切换、动画开关刷新后的恢复、明暗切换、导航以及关闭弹窗后的焦点；未出现页面控制台错误。运行中的首页已加载新资源，无需重启后端。设置截图位于本机 `outputs/motion-20261013/animation-settings.png`。
