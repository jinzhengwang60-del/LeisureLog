# 本机插件管理（批次 06）

> 本文保留架构开发阶段的设计与验证范围。文中的 `checkpoint/...` 中间标签与 `outputs/...` 证据为本地开发记录，不随公开 Git 历史上传；公开版本的复现与恢复以 [验证记录](verification.md) 和 [回退说明](plugin-rollback.md) 为准。

管理页面是核心的常驻入口 `/plugins`，管理当前已经登记的功能。列表、启停、权限选择、撤权和故障说明沿用运行管理器；本轮不安装、卸载或下载功能包，不选择 Python 模块路径。

## 操作边界

- 页面入口不依赖任何插件；全部停用、空集合、包缺失或设置损坏时仍能打开，并保留通往活动记录的入口。
- 操作前调用只读计划接口，版本、依赖和最低授权沿用宿主预检；不运行插件工厂、不启动任务、不保存设置。
- 启用时明确显示本次功能及依赖的权限。已经运行的依赖沿用实际授权；失败功能重试时沿用保存的授权，避免默认扩大权限。首次启用显示声明的全部权限，可取消可选项后再提交。
- 停用和撤权列出受影响的依赖功能，再按计划提交。撤销任一权限会停用整个插件及依赖方，后续可重新选择权限启用。
- 每次提交携带计划的设置版本；设置过期拒绝操作并要求重新核对。网络中断时只读取最新状态，不自动重复发送修改请求。
- 启用意图和真实运行状态分开展示。保存后启动失败、停用后任务未退出、接入资料暂不可用都明确说明；不把 HTTP 200 当作运行成功。
- 权限、依赖与错误信息仅是宿主元数据，不包含原始活动、标题、网址、配置文件内容或异常原文。界面用文本渲染，不解释插件名称中的 HTML。
- 数据库保持 0013，插件配置保持 version 1。增加的已保存授权字段仅用于状态 API，不改变持久格式。保留上一检查点及所有更早标签。

## 验收约定

用隔离 SQLite、固定插件定义与真实工作线程验证计划无副作用、依赖共同停用、权限选择、过期计划、配置损坏、失效选择清理、启动失败和停止超时。验证关闭游戏分析后核心采集仍可继续，恢复后已有人工类型仍保留。

执行本轮 Python 回归、前端操作逻辑检查、架构和代码检查。用独立测试网页进行真实浏览器交互；检查启停、只读授权、撤权、菜单变化和多种现有风格。验证资源随 Python 包一起提供，保存本地提交与 `checkpoint/core-plugins-manager-06`，不切换日常服务、真实数据或现有安装包。

## 实际验证（2026-10-15）

- 完整 Python 回归 **480 passed / 1 warning**，耗时 **128.47 秒**；新增 14 项管理接口与核心保留验证。前端行为 **43 passed / 0 failed**，其中 11 项管理请求、权限、失联、过期与停止状态检查。
- 浏览器实际操作通过：停用分析撤下游戏菜单；只授予汇总/统计后可启用；撤销统计授权停用分析；启动失败显示宿主说明而不泄露异常原文；停止超时禁止重启，真实任务退出后允许重试并清除过时提示。
- 两个网页窗口复现过期计划：另一窗口先保存停用选择，本窗口旧计划返回冲突、不重放请求，确认按钮失效并将焦点移到取消。成功关闭窗口后，焦点回到相应功能的新操作按钮；无可用按钮时回到刷新。
- 常驻入口覆盖六个核心页面、两个游戏页面和管理页。真实窄屏检查覆盖六套风格，390px 视口均无整体横向溢出；确认窗口可完整操作。配置损坏、空集合和失效选择的 API 验证通过。
- 用 analysis-05 的实际源码对照本版，12 个阶段的活动、Session、时长、游戏统计、人工覆盖和原始快照一致；旧代码能够读取和重处理新版合成库，配套回退配置正常。
- 实际构建并从独立 wheel 导入应用，管理页、计划接口和资源可用；Python 3.11 对 156 个文件检查语法，本次完整运行环境为 Python 3.13.9。没有重建 Windows 安装包或运行远端 CI。
- 架构、Ruff、前端脚本语法与空白检查通过。证据位于本机忽略目录 `outputs/plugin-manager-validation/`：`final-regression.xml`、`parity/report.json`、`final-package-check/report.json`、浏览器记录和截图。

## 隔离预览和复现

在本开发工作树运行以下命令；`preview-06` 必须是尚未存在的输出子目录，可以另取名称。测试服务关闭自动同步与备份，只生成示例游戏和活动，不访问日常数据库或真实 ActivityWatch。

```powershell
$env:PYTHONUTF8 = '1'
$env:PYTHONPATH = (Join-Path $PWD 'src')
& .\.venv\Scripts\python.exe `
  scripts/preview_plugin_manager.py `
  --data-dir outputs/plugin-manager-validation/preview-06 --port 8736
```

打开 `http://127.0.0.1:8736/plugins`。带有明显隔离标记；`--demos` 可另加启动失败与慢退出的验证模块，二者不进入正式应用注册表。需要结束时在该终端按 Ctrl+C。

回归使用新的 `--basetemp` 子目录；API 测试需要本机测试网络权限。对照可用 `scripts/verify_game_migration.py --analysis --baseline checkpoint/core-plugins-analysis-05 --output <新的 outputs 子目录>`，打包可用 `scripts/verify_extension_package.py --output <新的 outputs 子目录>`。均只使用合成资料。
