## 必须保持的架构约定

| 约定 | 现有实现与验收方式 |
|---|---|
| 一套来源和计时模型 | Adapter 输出统一事件；核心拥有原始快照、活动、Session 与计时，资料目录中的累计游玩时间不生成活动 |
| 数据归核心持有 | 插件不获得 Repository、数据库连接、任意 SQL、FastAPI 应用或独立核心库；宿主校验建议并提交事务 |
| 人工选择保持优先 | 人工分类、用户规则与 YAML 规则先于插件；游戏类型人工选择优先于来源标签；停用不删除原始记录和人工选择 |
| 扩展有明确入口 | 显式 PluginDefinition 与 HostExtensionBindings 组装；公共 SDK 复用 domain；运行器支持分析、分类、任务、目录和页面 |
| 故障范围受控 | 有界工作槽、时间预算、授权撤销、停止确认及依赖撤下；空集合核心与无关模块继续工作 |
| 分层可执行 | AST 检查递归依赖与循环；旧游戏耦合例外为零，4 条宿主/存储许可没有扩大 |
| 保存与恢复明确 | 原子保存插件选择，配置大小限制为 1 MiB；完整 ZIP 保存选择与校验值，恢复到独立目录核对 |

已有自定义分析模块的注入测试验证：复用现有投影能力时，可以在组装入口提供定义与绑定，不修改 main 的业务分支。需要新的核心数据能力时，先增加有权限和事务边界的窄接口。

同进程的线程预算与接口授权仍只适用于受审查的官方代码。它们不能强制终止 Python、约束全部 CPU/内存或隔离任意第三方页面和代码；第三方安装的隔离验收尚未完成。

## 官方功能的完整使用路径

| 功能 | 输入与职责 | 缺失、停用与恢复 |
|---|---|---|
| 基础活动记录 | ActivityWatch 的窗口、离开状态、网页；统一活动、Session、用途与项目、统计、人工修正和备份由核心负责 | 上游离线保留已导入记录；插件故障不替代或阻断基础来源 |
| Playnite 资料与识别 | 固定位置读取导出与进程绑定；名称、标签、程序等资料由宿主校验保存，再提供识别建议 | 缺失或损坏导出保留旧目录；停用撤下接入与识别，原始记录和历史资料保留；封面不能仅凭程序名满足标题条件 |
| 游戏统计、类型与偏好 | 读取宿主投影，统计已有游戏活动；人工类型建议由宿主保存；页面由受控资源清单提供 | 不要求 Playnite 正在运行；缺少资料、无记录和零计入时间有对应状态；停用页面撤下，重启或恢复后人工选择保留 |

游戏分析的三个授权模式：

| 模式 | 最低授权 | 页面行为 |
|---|---|---|
| 汇总 | 活动汇总、游戏统计 | 查看列表和偏好；游戏名称不提供明细入口，旧明细链接回到可用列表 |
| 明细只读 | 汇总权限加活动详情 | 查看月/日分布、游玩依据、当前类型和标签；编辑表单隐藏 |
| 可编辑 | 明细权限加人工类型写入 | 保存或恢复类型与标签；写入仍经宿主权限、事务和激活代数验证 |

页面只使用当前实际授权，不能用声明权限、已保存意图或其他模块的授权打开操作。刷新页面、打开明细与提交修改前读取状态；状态未知时关闭明细和编辑入口，统计数据仍由后端独立验证权限。保存响应丢失时不自动重放。

## 配套备份

完整 ZIP 现在包含活动数据库、分类规则、插件选择和校验报告。不存在选择文件时，将本版本的默认集合明确记录到 ZIP，不在运行目录创建文件；已有文件保留原始字节，损坏配置也保留原文用于排查。

配置快照通过宿主注入的字节提供者交给存储实现，插件不参与备份目录或文件名选择。补充文件名、数量和大小受限；失败清理未完成产物。数据库使用 SQLite 一致快照并独立恢复核对；配置是另行捕获的文件快照，不承诺跨文件同一时刻的事务。

单独下载 .db 不包含插件选择。恢复需要按 [存储说明](storage.md) 指定解压后的插件配置路径。当前仍是恢复到新位置的验证流程，没有新增覆盖当前数据的一键恢复；Playnite 外部程序、导出设置、其他环境配置和插件程序包不在该 ZIP 中。

## 后续独立包安装的验收门槛

安装器以后需要接到已有定义、资源与运行器，不能把任意模块路径或安装命令放进用户配置。落地前至少完成：

1. 包格式、来源、稳定 ID、接口/应用兼容版本、依赖、资源和权限的预检；预检不运行包代码。
2. 将包来源映射到受控工厂与资源根；验证当前 Windows 打包程序能够实际加载，区分安装和启用。
3. 分阶段安装/更新，确认旧工作停止后再切换；保存包版本与配套配置，演练启动失败恢复。
4. 卸载先计划依赖影响，默认保留核心记录与人工选择；需要新增数据结构时统一使用宿主迁移与回退验收。
5. 对官方包和第三方代码分别验证运行边界。当前不以官方线程测试声称任意第三方已经被隔离。

这些是后续实现约束，不是本批已经完成的安装能力。暂不建设在线市场或扩大插件数量。
