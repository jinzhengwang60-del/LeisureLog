# 源码版本与数据回退

[架构说明](plugin-architecture.md) · [源码运行与升级](local-deployment.md) · [存储与恢复](storage.md)

当前源码包含核心与两个官方模块，数据库保持 0013，插件选择格式为 version 1。更新程序、恢复配置和恢复数据库是三个不同操作；保存 Git 提交本身不能替代数据备份。

## 本次用途保存修复的回退边界

2026-10-26 更新以前的公开 main 为 [0b10387](https://github.com/jinzhengwang60-del/LeisureLog/commit/0b10387ae6283434c82f900296522b63a3a82444)，本次以它为父提交。源码版本号仍为 0.4.0b2，结构仍为 0013，没有增加持久字段。回退程序时保留最新数据库与配置，不能用旧活动快照覆盖新增记录。

以下 5c0a400、1f90115 说明属于更早的历史批次；它们不是本次直接父提交。本地检查点不包含在公开历史中。

## 更早公开版本的保留点

此前稳定性与界面更新以前的公开 main 提交为 [5c0a400](https://github.com/jinzhengwang60-del/LeisureLog/commit/5c0a400d34567900d0840e38273ac7d0b86c0adf)，它已包含核心与官方插件运行管理器。该次提交以此公开版本为父提交，继续保留公开历史，不合入本机私人维护历史。

更早的 [1f90115](https://github.com/jinzhengwang60-del/LeisureLog/commit/1f901152d2a57d37bf5dee354aa2d85172bec7b4) 是 2026-10-16 接入运行管理器以前的历史基线，另由 `backup/pre-core-plugins-20261016` 分支保留。

开发文档中的 `checkpoint/core-plugins-*` 是本地检查点，公开仓库不包含这些中间历史。不要把它们当作从 GitHub 克隆后可以直接检出的标签。对照脚本需要自行提供相应基线；普通回归按 [验证记录](verification.md) 运行。

## 更新以前

1. 保存尚未提交的源码修改，记录当前提交、运行目录和启动方式。
2. 在“存储”页创建并下载完整 ZIP，核对验证状态。另存实际使用的环境文件、游戏导出、进程绑定与自定义数据路径；完整 ZIP 不涵盖所有环境和外部程序。
3. 在线 SQLite 快照应使用 SQLite backup API，不能只复制正在写入的 .db 并忽略 WAL。
4. 在隔离目录验证目标代码与数据副本，关闭该实例的自动同步和自动备份，不让两个版本同时写入同一数据库。
5. 停止旧服务后，再保存最终一致快照，更新程序与依赖，然后使用原数据路径启动。

## 本次无迁移的程序回退

本次结构保持 0013，原始与人工选择的持久模型不变。恢复更新前的代码时，先退出新版后台，另存当前数据库和配置，再切换到保留的公开版本，继续使用当前兼容数据库。不要把旧活动快照直接覆盖回去，否则会丢失快照之后新增的活动。

更早基线 `1f90115` 没有插件运行管理器，不读取新版 plugin-state.json，游戏功能仍为原内置实现。回退到该基线不会保留“停用某官方模块”的运行效果；需要继续尊重该选择时，应使用包含运行管理器的版本或另行核对配置能力。保留插件选择文件便于恢复新版，不能宣称更早代码识别它。

稳定性批次的父版 `5c0a400` 已具备运行管理器；当前更新维持数据库 0013 与插件选择 version 1。回退该父版仍需在隔离数据副本上核对权限、插件启停与读写行为，不把这些兼容边界推广到未来版本。新版恢复命令与备份校验增强属于当前源码能力，应按相应版本的文档使用。

新版运行器内调整授权、停用或恢复功能，不删除核心历史记录和人工修正。未来回退到认识部分权限的旧运行器时，应使用目标版本配套的选择文件；先保存当前文件，不把新权限配置直接交给不兼容代码。

## 未来变更的恢复要求

| 变更 | 必须保留 | 恢复时核对 |
|---|---|---|
| 程序或页面，结构不变 | 旧程序、提交、配置与当前数据备份 | 旧代码能读取当前结构，不覆盖新增记录 |
| 独立插件安装或更新 | 旧包、激活集合、配套配置 | 旧任务已退出，失败可恢复旧包与集合；此安装能力尚未实现 |
| 插件配置格式改变 | 迁移前文件与版本说明 | 原子迁移、兼容检查及配套恢复 |
| 数据库结构改变 | 独立验证、迁移前快照、更新后新增记录 | 旧代码是否接受结构；降级或恢复经过独立演练 |

桌面入口拒绝未知数据库版本。未来有结构变化时，不能仅因旧表看似还在就宣称旧程序可用；也不能通过恢复旧快照声称新增记录天然保留。

当前完整 ZIP 包含数据库、规则、插件选择及校验报告，不包含独立插件程序包、外部 Playnite 设置或全部环境配置。恢复路径与插件选择的指定方式见 [存储说明](storage.md)。
